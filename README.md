# DOVA - Device Owned Voice Assistant
DOVA is a local first agentic voice assistant designed to co-exist with your system.

> [!CAUTION]
> **Use at your own risk, LLMs can be unpredictable.** We do not take responsability for any harm caused.

> [!WARNING]  
> DOVA is in early creation, changes are to be expected.

## How does DOVA work?
DOVA is internally powered by **[LangChain](https://langchain.com/)** as an universal harness for your models.

For comunications, DOVA uses **WebSockets** to comunicate with the client ***(yes DOVA has a client and a server)**

## Why does DOVA use websockets?
DOVA is using a websocket system to allow it to be ported to any systems allowing websockets.
With such method, DOVA can be seperated into a client and a "server", removing the need for corss-platform compatibility within a single project.

You could TECHNICALLY use it on a browser or even a phone and still have the same experience as a desktop (with the system's limitations of course)
